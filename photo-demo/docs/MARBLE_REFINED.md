## 本轮改变

1. 杯柄略向上校正，与杯沿更接近；蓝釉从原照有效蓝色区域延伸到边缘和未见侧面，避免背景色进入柄面。杯口、咖啡与杯身仍使用原照可见纹理。
2. 书封纹理向有效内域收缩后延展到边界，减少背景采样形成的锯齿色边；网格开启多重采样抗锯齿。书本与纸页仍沿用上一版共享支撑高度。
3. 用连续、不透明的三维桌面支持网格替代原来的局部 Gaussian 补片。内部保持接触平面，边界向 Marble 已观察到的高度和颜色接合，并加入轻微接触阴影。
4. 颜色采样排除桌沿下方的棕色像素。补面边界禁止重新混入旧书/杯的前景颜色；这消除了一个在 +12° 露出的扁平副本，并移除少量残余蓝色高斯。

全部处理在 Mac 本地进行，复用既有场景、模型和照片。没有调用收费生成 API，没有使用 3090，没有新增生成费用。照片、几何、SPZ 和截图继续被 Git 忽略。

## 大角度与自由移动

- ±12° 使用与上一版完全相同的轨道和原照投影，方便局部对照。
- 近桌绕行在 12°–45° 之间连续靠近桌面，此后沿较小半径绕行，提供 ±60°、±120° 停点。探索模式展开为单个宽画布。
- 180° 试验仍贴近窗帘并露出严重未观测表面，因此没有把该路径作为默认引导。自由移动可继续转头、平移和前后探索。
- 自由模式拖动是原地转头；右键/Shift 拖动平移，滚轮前后移动，WASD/QE 或屏幕按钮移动，Home 复位。仅有大致房间边界约束，没有精确家具碰撞系统。

## 证据与限制

局部检查包含电脑、杯子/书在0°与±12°，保存同机位新旧图。桌面原补片的明显轮廓、旧书扁平残影和部分杯柄色边得到改善。书页薄边、杯口和背面仍是近似；较大角度仍可能出现桌后空洞、拉伸和外围家具失真。连续补面也简化了原有细小光照变化，不能称为照片级无痕融合。

曾尝试沿源物件轮廓延长隐藏桌面，但在120°产生不自然的突出边界，已撤回。较大角度的桌后缺失仍然存在；下一阶段由建模场景承接，不保留这次错误延伸。

构建时曾将旧书本颜色混入新桌面，支持纹理含2,237个明显蓝色前景像素；在禁止前景混入后该计数为0，已加入回归检查。这个指标只检查该具体错误，不代表整个场景没有重影。

相机检查遍历2,401个角度采样，±12°与旧轨道一致，往返确定；每0.1°最大位置步长约7.7毫米、最大旋转步长约0.00194弧度。旧141个运行文件的哈希全部保留。没有把前几轮的28停点检查算成本轮结果。

本地证据位于 `evidence/marble-refined/`。`asset-qa.json`记录实际清理数量、前景泄漏和保全结果；`camera-qa.json`记录路径连续性；`browser-qa.json`记录本轮实际页面检查。180°截图是未采用的边界试验，不是通过的展示机位。
