实际制作顺序：

1. 保留 Hi3D 表面、UV 与 PBR 贴图，移除原头，恢复身体中立姿态。女生旧书包与身体分离，独立处理袋带，避免融合衣料在跨步时牵拉腿部。
2. Blender 使用临时封闭人体代理做骨热权重，再把权重转移回原始高精表面；删除代理，归一化到每顶点最多四个影响骨骼。对肩腋、肘、衣摆、手腕及整鞋单独校正。男生增加前臂扭转骨，避免把掌部转向集中扭在手腕一点。
3. 两女生分别采用 CMU `07_05`、`07_04` 的真实慢走；第二段连同根位移和全身姿态一起拉伸到四秒。按目标人体比例重定向，保留来源步幅与位移的关系，不再用独立匀速平移假装走路。足底接触窗、踝部 IK、骨盆修正及整鞋包络用于消除滑步、穿地和双脚同时漂浮。
4. 男生以 CMU `06_14` 投篮段的骨盆、躯干、膝肘关系作为动作参考并重定向；针对场景制作双手持球 IK、手指 FK、脚部支撑与收势。主投臂按共同屈肘平面传递旋转，腕部旋转分配到四段前臂扭转骨；出手后伸臂随腕，收手沿肩周弧线回落，避免线性腕路径经过肩附近而把肘部过度折起。球由 `BallSocket` 跟随到一秒离手，随后接场景球路。CMU 没有手指动作捕捉，手指贴球约束属于本次制作，不能标成来源自带的手部动捕。
5. 将约束结果烘焙为四秒、60 Hz 的真实骨骼 animation clips，导出 GLB 的 skins、joints、inverse bind matrices 和动画轨道。默认节点必须保存 bind/rest pose；不要把某个动画帧当默认姿态导出，也不要把身体展平为普通静态 Mesh 或 morph 动画。

运行时由 `cases/after-school-rewind/viewer/rigged-actors.js` 保留完整 GLTF 场景和 SkinnedMesh。第二女生在装配前通过 `SkeletonUtils.clone` 获得独立骨架、独立 mixer/action；不可共用正在变形的骨架。每帧按绝对时间采样同一段 clip，支持正放、倒放和任意跳时；根位移已在动画内，运行时只做统一等比缩放、朝向和场景放置。

独立头部先按旧头资产的实际剪裁规则装配到身体 rest 坐标，再通过 `Head.attach(mount)` 挂到头骨；此时尚未播放动作。`restHeadMount` 使用导出默认 rest 姿态的身体局部坐标，须实测颈部位置；与头骨原点之间可以有明确的装配偏移。身体、头部不得按不同坐标轴各自归一化。运行时为女生根据实际 t=4 根位置对齐校园既有终点，不把 metadata 的步长当作新的线性位移。

关键 metadata 契约如下，实际数值以每个固定候选附带的 JSON 为准：

| 字段 | 作用 |
| --- | --- |
| `height`, `coordinate`, `rootBone`, `headBone`, `restHeadMount` | 米制、glTF Y-up、+Z 朝前；规定统一尺度、实际根骨锚点及 rest 头部挂点。 |
| `neckForwardMetres`, `neckRearInsetMetres` | 对男生已裁切的下颈基部做实测局部贴合；不改变脸部、头部整体比例或骨骼动作。须随正侧背实机近景复核。 |
| `clip`, `companionClip` | 主女生用 `walk`，第二女生用 `walk-companion`；男生用 `shoot`。 |
| `clips[clipName].surfaceSamples` | 两段行走各有真实表面点和支撑窗；不能把第一段的接触时间直接复用到第二段。顶层 `surfaceSamples` 只用于单 clip/旧格式兼容。 |
| `surfaceSamples[]` | `mesh` 与 bind-local `position`（或明确顶点索引）、`kind`、`side`、`id`；足部另有秒制 `planted` 区间。QA 使用真实蒙皮后的网格顶点世界位置。 |
| `soleRegions[]` | `{mesh,min:[x,y,z],max:[x,y,z]}`，覆盖完整鞋体的 bind 坐标范围；QA 对所选全部真实顶点蒙皮后求最低点，不能只选一个“好看”的脚底点。 |
| `ballSocket`, `releaseTime`, `ballRadius` | 男生持球锚点、离手时刻及球的实际半径；双掌/指腹间隙从变形表面到球面测量。 |
| `sourceReplaced`, `noDetachedHandFragments`, `removedHeadTriangles`, `provenance` | 保存实际来源、原头删除数和手部碎片检查结果，不用虚构删除数量满足断言。 |

`rewindMotionSample(t)` 返回三人的实际骨矩阵、足部表面点、整鞋高度范围、双手接触点与球位置；采样后必须恢复现场时间和显示状态。它只供 QA，不在渲染循环扫描所有鞋顶点。

动作数值门槛：0–4 秒按 60 Hz 采样；正放、逆序和跳时结果误差不超过 `1e-6`，诊断结束恢复现场状态；三人均保留真实 skin、bones、clip。持球期每帧双手实际掌/指腹到球面间隙不超过 25 mm。所有人物整鞋最低点不得低于地面 5 mm；慢走每帧至少一只鞋的实际最低点不高于地面 25 mm，投篮起跳段不受此上限限制。各人物声明的固定支撑段至少持续 0.12 秒，材料点平面漂移不超过 10 mm、高度变化不超过 15 mm，接地高度在 −5 至 25 mm 内，两脚均须有可测支撑段。

离手姿态补充门槛（作者按本段投篮确认，非医学关节范围）：从导出骨矩阵取真实肘、腕、四指掌指根位置，比较“肘→腕”与“腕→掌指根均值”方向，0°表示同向，接近180°表示掌轴折回前臂；全周期两手不超过95°，保留原持球期约76°的腕屈曲。主投右臂在离手后0.20–0.60秒完成伸展，“肩→肘”和“肘→腕”方向变化不超过45°；持球和收回休息阶段不强制肘伸直。已用 `abc76d27a72ca904` 的真实保存样本复现新门槛失败：右腕方向171.798°，发生于1.2167秒。不得用目标控制器姿态或删除故障时间段代替真实导出骨层测量。

腕角合格也不等于蒙皮合格：一次伸臂候选在1.15秒出现肘部尖锐收窄。实际 GLB 的1405个上/前臂混合权重点中，最坏点权重约50%/50%，LBS 混合矩阵 determinant 为0.00896、最小奇异值0.09467，支持两骨旋转相互抵消的判断。修复方向是统一屈肘平面和roll分配，不能仅把手掌方向改正确。矩阵指标目前作为诊断证据，尚未设通用硬门槛；仍检查持球期及离手过渡的真实肘部表面、速度连续性和头手穿插。

画面证据通过真实鼠标、WASD、R 键路线记录正侧面、手部和脚部近景，保存完整正常速度 WebM 与 0.25× MP4；慢放使用时间拉伸，不合成中间姿态。数值通过不能证明肩腋衣料、手指、颈部或步态观感自然，仍须审看连续画面和近景。独立 asset lab 的通过也不能替代最终校园包验收。

本次发现过三种误判：单个接地点漂移仅约 3 mm 时，完整鞋跟仍可穿地约 81 mm；已标记的支撑段全部通过时，未标记的换脚过程仍可出现 62 mm 双脚离地；持球期双手到球面间隙通过时，离手后掌轴仍可折回前臂约 170°。因此验收同时检查固定材料点、完整鞋体、全部时间采样及离手后的姿态。60 Hz 验收还抓到过 30 Hz 关键帧之间 0.454 mm 的越界，修复约束/烘焙，没有放宽门槛。

## 2026-11-16 收手末态扭曲回归
