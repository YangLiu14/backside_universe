# 中英文界面

[项目首页](../../README.md) · [开发指南](DEVELOPMENT.md)

相簿、工位故事、小狗身体博物馆、独立书屋与模型审阅页共用右上角的「中文 / English」切换。切换即时生效，不重新加载模型，不重置相机、纸船、开门状态或游览进度。

## 语言选择

默认中文。`?lang=en` 或 `?lang=zh` 优先于本机保存的选择；没有参数时读取 `backside-universe:language`。显式切换会更新本机偏好及当前 URL，刷新和分享都能保留语言。

相簿和保留的场景 iframe 通过同源 storage 事件与消息同步。语言变化不会触发 `show()`、重新创建 iframe 或重置三维场景。存储不可用时仍可用 URL 参数和同源消息切换。

## 界面与场景文字

- `dist/i18n/core.js` 提供 `t()`、`getLanguage()`、`setLanguage()`、`onLanguageChange()` 和 `localizedTexture()`。
- `messages.en.js` 是人工整理的英译表，以原有中文短语为键，覆盖界面、状态提示、房间、故事与导览字幕。组合标签复用相同短语；等待秒数与物件数量单独格式化。
- `index.js` 为已有静态页面及动态 DOM 更新适配文字、标题、图片说明和无障碍标签。每个节点保存原文，不以当前已翻译文字反复翻译。观察器仅关注文字和相关属性，并在写入时断开以避免循环；WebGL 的相机、帧统计等属性不进入观察范围。
- 新交互可直接使用 `t()`。状态判断使用 ID 或阶段值，不依赖翻译后的按钮文案。需要保持原样的内容可标记 `data-no-i18n`。
- 纸条、手机工作群通知、书屋书页使用 `localizedTexture()` 在原纹理上重绘。英文按自己的行长排版；贴图销毁时移除监听。输入照片和生成模型中原有的图像内容不被改写。

英文控件允许换行，窄屏调整展馆索引和按钮排列。浏览器的 `lang` 属性、按钮选中状态、ARIA 标签与页面标题同步更新。

## 英文旁白与本地资源

小狗导览有六站路线和六段馆内英文旁白。文件位于 `dist/canine-museum/assets/digestion/en/`，语言切换时替换音源并保留当前站点与路线时间。六站音频长度与中文路线相同，避免改变原有相机旅程。馆内切换语言从该馆讲解开头播放；暂停、静音、退出和后台可见性仍使用原有播放器。

音频不进入 Git。来源文本、声线、时长与 SHA256 记录在 [narration.en.json](../dist/i18n/narration.en.json)，恢复位置也已加入 [本地资产清单](local-assets.json)。在安装 FFmpeg 的 macOS 上，可用系统 Daniel 英文声线重新生成，不需要调用付费接口：

```sh
python3 photo-demo/scripts/build-english-narration.py
```

已录制的旧版消化导览 MP4 仍保留中文音轨，英文界面的下载链接对此作了标注。实时游览使用所选语言的字幕与旁白。

## 验证与发布

本地服务启动并按 [浏览器配置](MARBLE.md#浏览器检查配置) 配置 Playwright 后，从 `photo-demo/` 执行：

```sh
npm run check:language
npm run check:album
```

语言检查覆盖英文五岛完整循环、切换前后相机与贴图、相簿和 iframe 同步、刷新记忆、英文音源、馆内字幕与手机视口布局；相簿回归确认按需加载与重访不重复下载模型。模拟手机视口不等同于真实手机 GPU 验证。

静态发布包需要同时包含 `i18n/` 和英文音频。主打包器已包含语言目录，小狗场景资源目录包含英文音源。更改词表或场景文字后应重新构建对应发布包；仅更新相簿首页不能替换已固定版本的三维场景。

公开相簿已使用双语版本，固定版本号记录在 `deploy/releases.json`。资源库的 `_redirects` 由 `deploy/scene-redirects.txt` 生成，将首版两个场景的旧地址代理到其保留的 Netlify 部署；发布资源 ZIP 时需一并保留此文件。它不重定向到最新场景，因此已经打开的旧作品仍读取原版本资源。
