## 最新实现的关键点

`scripts/build-solid-objects.py` 在原 Gaussian 相机坐标下拟合电脑和杯子，生成 `objects.json` 与清理后的背景。电脑屏幕和底座共享铰链；杯碟倾斜和杯身位置按原照片拟合。场景单位来自深度推断，未经实测。

`dist/solid-object-lab/solid-objects.js` 用固定源相机可见性控制照片纹理投影。实体写入深度缓冲，背景 Gaussian 遵守遮挡；可见纹理不会随用户拖动切换。新露出的材质仍是估计。没有用屏幕空间照片淡化或后期模糊遮住缺陷。

清理前景时发现，简单深度阈值会误删已分离桌面的边缘，产生形似旧杯沿的弧线缺口。最终按表面归属保护背景，再校准杯碟附近支持面与接触阴影。共移除 27,850 个 Gaussian，背景保留 1,554,012 个；实体部分包含六个部件。

## 验证记录

- 电脑/杯子分别检查 0°、±6°、±12°；扩大到杯碟外侧的背景检查，没有旧蓝色杯子残留和透明缺口。
- 四种观察范围 × 七个角度，共 28 个停点检查通过；往返回到同一角度后，相机与截图像素一致。
- 同角度版本切换保留相机和投影，切换暂停播放；拖动、键盘、播放暂停及手机布局通过，无 JS 错误。手机视口不代表真机性能验证。
- 上一版补全页七个文件与原主 demo 的 81 个文件在实体小样完成时哈希未变。此次 Git 整理取消了部分文件的跟踪，但本地资产仍保留。

原视角 RGB 平均绝对差（0–255，越低越好）：

| 范围 | 上一版遮挡补全 | 实体表面版 |
| --- | ---: | ---: |
| 电脑裁剪 | 7.666 | 5.901 |
| 杯子与书裁剪 | 5.092 | 6.087 |
| 整幅图 | 5.177 | 5.234 |

这些是固定渲染尺寸下的原视角对照。电脑保真改善，杯子区域有轻微代价；没有新视角实拍真值，不能用该指标证明隐藏面正确。背景蓝色残留检查用于确认前景分离，不能当作「重影减少百分比」。

InfiniSplat 原始 3090 运行得到 1,476,727 个 Gaussian，编码推理约 1.74 秒、GPU 峰值约 5.16 GiB，不包括加载和导出。后续补全与实体拟合在 Mac 本地完成，没有再次调用收费模型。

## 仍需处理

杯柄和新露侧面的形状、纹理尚不完全准确。书本、便笺、耳机、台灯、椅子和房间外围沿用旧 Gaussian，仍会出现拉伸与重影。主 demo 的照片交接尚未整合最新小样，更不能据此声称单张照片已获得完整的 180° 实景。

下一阶段应先由实际画面对比确认电脑/杯子的质量收益，再扩展其他桌面物件，并评估怎样在连续绕行中接入度假世界。资产来源和恢复方法见 [ASSETS.md](ASSETS.md)，主 demo 历次实现见 [MAIN_DEMO.md](MAIN_DEMO.md)。
