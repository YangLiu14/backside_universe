# 照片 → 背面宇宙：工作流复核（2026-11-12）

复核对象是仓库当前的 Skill、执行器、通用播放器和《外婆》专属播放器。结论：**选定故事后，agent 会持续制作；默认 MCP 路径在付费生成前等待用户确认当前报价。** CLI 负责有状态、可复跑的计算；agent 负责创作、汇总国际站 MCP 报价供用户确认、适配故事交互和看片。单独启动一次 CLI 不能无人值守地完成这些外部步骤。

| 环节 | Agent 做什么 | 流水线据什么继续 |
| --- | --- | --- |
| 照片与故事 | 给两种可操作的构想；已有明确故事就直接采用。选定后写观众落点、目标物、动作反馈，决定通用播放还是专属体验。 | `init / story` 关联原照哈希，校验主体框、whole/insert、动作和独立分件。专属案例须有播放器与检查脚本。 |
| 实景与概念 | 发起本地单图深度/Gaussian，同时制作并展示概念图。用户要求等审核就暂停相关生成；已要求全权决定则直接继续。 | 审核按概念图版本登记；可选审核发出 60 秒后默认继续。暂停不阻碍实景和独立外壳。 |
| Hi3D 建模 | 新作品默认通过国际站个人 MCP 上传参考图、免费报价；用户可一次确认列明的多份报价，随后按原任务号跟进。旧作沿用已登记路径。 | 核对账户指纹 → 记录报价 → 确认后一次提交 → 任务输出与 GLB 哈希。提交结果不明先对账。官网和开放平台可显式选择。 |
| 装配 | 通用故事配置开口、机位和一个动作。能进入的空间另定义边界、光源、实体动作、可达视角和场景证据。 | 通用模板提供预绘和连续绕行；专属播放器可直接复用室内控制器。打包校验模型与实景来源，按内容生成 release。 |
| 验收与返修 | 从真实入口走一次，用最初报告问题的机位和操作复测，看清目标是否可见、叙事线索是否成立。只修改失效的一层。 | 两种播放器均先执行桌面/窄屏首次绕行检查。案例继续检查自己声明的玩法；可使用直线扫掠避让和固定镜头动态像素检查。仅成功的本轮 QA 写通过报告。 |
| 交付 | 看片；交付相簿时核实进出与重访，按约定同步便携包、受影响的剧照或短片。 | 独立 release 可直接预览。当前仅有匹配安装器的项目会自动装入已有相簿，公开发布另行决定。 |

## Standards：工程可靠性

已验证发布目录损坏时 build / QA 不再接受同名版本；预览和《外婆》安装前也校验发布内容。复验失败会撤下原通过报告，预绘期间的着色器错误能使公共验收失败。《外婆》需恢复的七张纹理（含旧作品使用的一张）已登记路径与 SHA-256；原件仍需来自对应试玩包或私有备份。

**仍有一处顺序风险**：[`drive`](../pipeline/drive.py) 先按浏览器报告执行安装器，再返回 `inspect_keyframes`。因此本地相簿可能已经展示一个机器验过、但 agent 尚未检查构图的版本。实际看片时，《灯下夜市》的交接帧里原照片背景与深色展台仍有清晰的竖向分界；它通过了绕行性能检查，视觉衔接却仍有优化空间。普通作品的 `preview` 也允许查看仅 build 的版本。建议把制作预览与最终交付分开：看片结论绑定 release，完成后再更新相簿中的交付版本。这是 agent 验片，不需要增加用户确认。

## Spec：下一张照片能否按同样的方式完成

1. **相簿登记尚未通用。** [安装器选择](../pipeline/drive.py)按作品 ID 查找专属脚本，[首页](../dist/index.html)包含作品卡片。新 ID 可通过全部通用验收，却没有相簿入口。优先从作品清单生成卡片，测试从相簿进入、返回与重访；保留本地作品与公开版的区别。
2. **室内控制可复用，任意故事动作仍须适配。** [故事校验](../pipeline/project.py)内置点灯、发声、转动；可进入空间现在能复用[走动控制器](../pipeline/viewer/room-walk.js)，但可走地面、碰撞物、视线目标及“拉凳入座”之类的动作仍由案例提供。下一步可把反复出现的进入/返回、直线拖动物、落座锚点做成可配置组件，以新照片验证，再扩大动作库。

## 验证范围

国际站 MCP 用隔离作品和合成图实测到免费报价：新建作品默认走 MCP，账户与已核对指纹一致，进程重启后取得同一报价，前后积分不变。收费提交、丢回执、任务恢复和下载校验用模拟回执验证，未花积分新建模型。

用同一份新执行器在隔离目录重建并运行两件已有作品：《灯下夜市》走通用模板，《外婆》走专属模板。测试复用本地既有 Hi3D 资产，无新生成/扣费；窄屏为 Chromium 触控模拟，不代表真机性能。通用版本 `c7bb7fc0712ada66`、专属版本 `91d93f9199715762` 的四份设备结果中，交接段均无进度前进而机位不动的采样，首绕均无被监测的静态资源上传或程序链接。另用旧播放器、原穿模凳位、损坏着色器和受损发布包做反例，确认检查会失败。构图、时代感、暖光是否自然仍须看片。

具体制作方法、检查调用方式和适用条件见[体验质量与返修手册](../../.agents/skills/backside-universe/references/quality.md)；MCP 报价、官网提交和中断恢复见[执行手册](../../.agents/skills/backside-universe/references/production.md)。
