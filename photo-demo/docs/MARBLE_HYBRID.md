# Marble 房间与原照物件对照

独立入口：`http://127.0.0.1:9988/marble-hybrid-lab/index.html`。

保留 `/marble-lab/` 与所有旧实验。本页复用已有 Marble 1.1 世界，不调用 World Labs、Hi3D 或其他收费模型，不需要 3090。新增生成费用为 0。

## 替换内容

- 保留原始 192 万 Gaussian 场景的空间、颜色、尺度与旋转；在衍生 SPZ 中仅将选中的 19,363 个前景 Gaussian 的 opacity 清零。未选中的属性逐字节不变。
- 电脑与蓝杯复用 `solid-object-lab` 已校准的实体几何和拓扑；书上小物件复用原 `note-hi3d.glb` 和家具配准记录。
- 原 Marble 书面与校准纸页高度不同，因此同步重建书的封面、书页和支撑平面，避免悬空或穿插。
- 原物件删除后露出的桌面用固定三维 Gaussian 支撑面补齐。颜色从已有 Marble 桌面拟合，边缘羽化；没有覆盖整个房间，也不在旋转中叠加一张屏幕照片。
- 使用原照片投影纹理和源机位深度可见性约束。原照看到的表面恢复屏幕、键盘、蓝釉、书封与纸页细节；新露出的侧背面使用近似基础材质。

坐标转换保留源机位投影，并按 Marble 桌面重新确定深度与接触高度。它不是完整的实测刚体恢复：纸页和书本采用共同高度映射，253 个纸页顶点约束到既有 SAM 轮廓。相机沿用 Marble 页的近似配准，不能据此声称整张照片像素级一致。

## 操作

原照在左，三维结果在右。可切换整房、桌面、电脑、杯子与书；切换「Marble 原版／替换物件版」保留当前相机。

- **±12° 检查**：拖动、滑杆、五个停点、往返播放。
- **大角度绕行**：范围 ±180°，提供 ±45°、90°、180° 停点。当前固定半径路径在 90°–180° 会穿过靠近书桌的墙面；属于探索功能，不是可交付的背面展示镜头。
- **自由观察**：左键拖动绕目标转动；右键或 Shift 拖动平移；滚轮前后移动；WASD / QE 位移；Home 或按钮复位。未实现碰撞约束。
- 检查开关：隐藏实体、关闭照片纹理、标出实体范围、用亮色标出透明缺口。

## 本次验证与已知限制

实际浏览器检查了电脑、杯子与书在 0°、−12°、+12° 的画面，以及 45°、90°、180° 大角度。电脑屏幕/键盘、蓝杯与纸页比原 Marble 更贴近源照片；书下原本出现的三角透明缺口已补齐。

同机位 A/B 的 camera matrix 和 projection matrix 完全一致；经过 −12°、+12° 返回 0° 也一致。自由拖动、键盘位移、滚轮移动和 Home 复位生效。此轮未重新完成旧页的 28 停点或手机全套检查，不能套用旧页的测试结果。

杯柄、书本细边和桌面补面仍有接缝、色差及残留阴影；它们尚未达到无痕融合。较大角度会露出近似背面和 Marble 本身的拉伸/缺失。没有新视角实拍真值，不能证明遮挡部分真实。主 demo 的照片转场、度假世界没有改动，也尚未接入本实验。

资产检查覆盖开始时已有的 132 个运行文件，全部 SHA256 未改变；前景清理只修改目标 Gaussian 的 opacity。电脑/杯子 4,112 个顶点在新旧源机位之间的投影差最大约 `0.0000041 px`，只证明坐标转换保留了既有校准，不是模型对真实照片的重建误差。实体底部位于共同桌面之上，书面高度一致。

本地证据在 `evidence/marble-hybrid/`：`asset-qa.json`、`browser-qa.json`、原位/±12°截图、大角度穿墙边界截图及旧文件哈希快照。媒体与生成几何继续忽略。

## 复现

在 `photo-demo` 目录，先恢复原 Marble SPZ、原照片、原物件/SAM 资产、Hi3D 纸页与原位 Marble 渲染截图 `evidence/marble-lab/registered/render.png`。Python 依赖为 NumPy、SciPy、Pillow、OpenCV；复用现有环境：

```sh
experiments/gaussian/.venv/bin/python scripts/build-marble-hybrid.py
experiments/gaussian/.venv/bin/python scripts/check-marble-hybrid.py
```

`check-marble-hybrid.py` 的旧版本保全检查依赖本次开始前保存的 `evidence/marble-hybrid/preservation-before.json`，该快照需从本地证据备份恢复。构建器限定为当前观测到的 SPZ v2、SH degree 0，不是通用 SPZ 编辑器。所有输出写入新页 `assets/`；旧 SPZ、GLB、源码均不覆盖。只有小型 `scene.json` 可纳入 Git。
