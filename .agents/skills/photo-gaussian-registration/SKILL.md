description: 从一张实拍照制作可小角度观察的 Gaussian 实景，或校准照片与替换网格的源机位。适用于照片进入三维场景的起始段。
---

把原照、Gaussian 和建模世界分开验收。工位案例的房间由 Marble 生成，但电脑与杯子的形状依然需要校正；深度推导的 Gaussian 则只能保住拍到的那一层。

1. 固定原文件、尺寸、方向、哈希及画面裁切。给新案例单独的输出和缓存目录，保留原图做 0° 对照。
2. 复用「工位背后的年假」制作路线时，使用完整原照生成私有 Marble 世界。参照 `photo-demo/docs/MARBLE.md` 和 `photo-demo/scripts/marble-world.py`，为新照片绑定独立的输入哈希、输出目录与任务状态。记录 operation ID、world ID、SPZ 哈希及坐标元数据，确认浏览器加载了这一份 SPZ。若任务只要求本地小视差实验，DA3-BASE 与 BLUNT 的流程见 `photo-demo/experiments/gaussian/README.md`，交付时写明所用方法。
3. 保存完整 fx、fy、cx、cy、图像尺寸、轴向与尺度语义。在同一裁切下，用分散的特征点对齐源相机。物体落脚面与面部等辨识点分别检查；关键点重投影误差不能证明遮挡面的形状。
4. 固定照片投影在源相机，随后移动观察相机。分割按轮廓，剔除旧物件还须结合深度与支撑面；先在不含替换件的视图里找残影，再检查实体。转动直到首次出现明显裂缝或拉伸，记录可用角度。
5. 交付原照、实景文件、可重建的相机/资产记录，以及 0° 和交接前的同裁切图。说明哪些表面来自照片，哪些只由单目深度推断。

工位的坐标转换、桌面重影和相机残差实例见仓库内 `photo-demo/docs/MARBLE_WORKFLOW_REFERENCE.md`。其中的尺度、角度和机位不适用于另一张图。
